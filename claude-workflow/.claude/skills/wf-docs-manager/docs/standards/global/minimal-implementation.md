## Minimal Implementation

### Build What You Need
Only create methods, classes, and functions that will actually get called.

### Clear Purpose
Each method should either be called or improve code readability; nothing else.

### Delete Exploration Artifacts
Remove helper methods and utilities written during development that ended up unused.

### No Future Stubs
Don't add empty methods, placeholder functions, or interfaces "for future extensibility".

### No Speculative Abstractions
Leave out factories, strategies, or adapters unless there is an immediate need for them.

### Review Before Commit
Before finishing a task, check that every new method has a caller or serves a clear readability purpose.

### Unused Code Is Debt
Delete dead code promptly; it confuses readers and increases the maintenance burden.
